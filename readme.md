# 🍽️ Restaurant Ordering App

A responsive restaurant ordering application built with React, featuring authentication, menu browsing, cart management, and a complete Stripe checkout flow.

🔗 **Live Demo:** https://restaurant-website-eight-tan.vercel.app/

## ✨ Features

- 🔐 User authentication with Supabase
- 🛡️ Protected routes for authenticated users
- 🍔 Browse menu items by category
- 🔎 View individual product details
- 🛒 Add, remove, and update cart items
- 💰 Real-time cart totals and order summary
- 💳 Secure checkout using Stripe Payment Element
- 🎞️ Promotional homepage slider and featured offers
- 📱 Responsive design with mobile-friendly navigation

## 🛠️ Tech Stack

**Frontend**

- React
- JavaScript
- Vite
- Tailwind CSS
- React Router

**State & Data**

- Redux Toolkit
- TanStack React Query

**Backend & Services**

- Express.js
- Supabase
- Stripe
